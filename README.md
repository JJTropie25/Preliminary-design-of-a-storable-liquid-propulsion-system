# Preliminary Design of a Storable Liquid Propulsion System

MATLAB coursework project for the Space Engineering degree (Politecnico di Milano) — preliminary design of a storable bipropellant liquid rocket engine.

## Contents
- `PS_SIZING.m` — overall propulsion system sizing
- `CombustionChamberDesign.m`, `CombustionChamberDesignAlternative.m` — combustion chamber sizing
- `NozzleDesign.m`, `NozzleDesignAlternative.m`, `NozzleDesignCompletement.m`, `NozzlePlot.m` — nozzle design and contour plotting
- `InjectorsDesign.m`, `holes_doublet.m`, `holes_general.m` — injector plate and hole pattern design
- `CoolingDesign.m`, `hotgasside.m` — regenerative cooling and hot-gas-side heat transfer analysis
- `Propulsion_project.zip` — full project report and archive
